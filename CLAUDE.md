# Project instructions

Follow the complete repository rules in `AGENTS.md`.

Before implementing work, inspect the project and current deployment assumptions. Preserve `migracion-siteground`; production is the Vercel Next.js project on `main`.

Keep factual scientific and commercial claims verifiable. Protect enquiry data, report form success only after provider acceptance, and never send personal data to general analytics.

Use the Golden Tracking Standard in `.agents/memory/golden-tracking-standard.md`. Update `DEVLOG.md` for each meaningful checkpoint and keep it in the same commit. Use feature branches and the preview/review workflow; do not publish unreviewed changes to production.
